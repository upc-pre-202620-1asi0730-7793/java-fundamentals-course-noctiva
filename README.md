# Fundamentos de Java para Principiantes

Repositorio educativo del curso introductorio de Java.

## Organización de los materiales

- `starter-files/`: ejercicios iniciales.
- `completed-examples/`: demostraciones y soluciones.
- `scripts/`: guiones de las lecciones.

El plan y los materiales se incorporan mediante ramas temporales y pull requests hacia `develop`.
