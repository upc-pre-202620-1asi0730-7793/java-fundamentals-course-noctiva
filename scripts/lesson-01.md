# Lección 1 — Tu primer programa en Java (2 minutos 52 segundos)

**Objetivo:** comprender qué es programar, conocer la estructura básica de un programa en Java y mostrar mensajes en la consola.  
**Público:** estudiantes de 12 a 17 años sin experiencia previa.  
**Herramienta:** editor Java online gratuito, sin instalación.

## 00:00–01:25 | Introducción y conceptos (diapositivas)

- **00:00–00:30:** Portada «Lección 1: Tu primer programa en Java». Explicar qué es programar usando la analogía de preparar un sándwich paso a paso.
- **00:30–01:00:** Presentar Java y la estructura base: la clase `Main`, el método `main` como punto de inicio y `System.out.println` para mostrar mensajes en la consola.
- **01:00–01:25:** Señalar las reglas de sintaxis esenciales: escribir los textos entre comillas dobles (`"..."`) y terminar cada instrucción con punto y coma (`;`).

## 01:25–02:20 | Demostración en el editor Java online

Escribir progresivamente el programa del archivo `../completed-examples/lesson-01/Demo.java` (en el editor, usar `public class Main`).

1. Crear la clase `Main` y el método `main`.
2. Escribir `System.out.println("Hola, mundo!");` y ejecutar el programa.
3. Agregar una segunda instrucción con el nombre del futuro proyecto: `System.out.println("Registro de estudiantes");`.
4. Ejecutar nuevamente y comprobar ambos mensajes en la consola.

**Salida esperada:**

```text
Hola, mundo!
Registro de estudiantes
```

## 02:20–02:52 | Práctica y cierre

**Desafío:** crear un programa que muestre una bienvenida, el nombre de una escuela y una frase sobre lo que se quiere aprender. Invitar a pausar el video y completar `../starter-files/lesson-01/Main.java`.

**Salida esperada:**

```text
Bienvenido a mi programa
Escuela: Los Pinos
Quiero aprender Java
```

**Cierre:** Hoy aprendimos qué es programar, qué es Java y cómo mostrar mensajes en la consola. En la siguiente lección aprenderemos a guardar información utilizando variables.
